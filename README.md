# Geodesy Tools

Here are a series of scripts I regularly employ when analyzing GNSS time series. For example, 'remove_geocenter.py' uses the annual and semi-annual geocenter model of Altamami et al., 2023 to predict and remove seasonal geocenter motion. This is important when analyzing GNSS time series that were processed in the ITRF20 reference frame if you want to study deformation of the solid Earth's figure. I will update and add to this as time goes on.
